# Robocon Timer Maker

**タイマーに進行を合わせて、ロボコン大会を盛り上げよう！**

1〜3部門のロボコン大会を、セッティングから試合、次の試合まで一定の間隔で進行するためのタイマーです。部門ごとに準備時間や試合時間を変えながら、**使用する全部門の試合を同時にスタート**できます。

ブラウザー上でそのまま使えるほか、音声付きのMP4動画も作成できます。画面・効果音・BGMを1つのHTMLファイルに収めているため、端末に保存すればインターネット接続なしで利用できます。

**[アプリを開く](https://jkawamata.github.io/robocontimer/)** · [GitHubリポジトリ](https://github.com/jkawamata/robocontimer)

現在のバージョン：**V1.39** ／ 作者：**川俣純**

## 主な機能

- 使用する部門を1〜3部門から選択し、部門名・色・セッティング時間・試合時間を変更できます。
- 全部門に共通の開始カウントを表示し、試合を同時に開始します。
- 試合開始から次の試合開始までの間隔を指定し、待機時間を自動で調整します。
- 効果音、試合中・試合間のBGM、残り時間を知らせるピアノ音を再生できます。
- 大会名の表示、文字の太さ・書体・大きさの調整、全画面表示に対応しています。
- 名前を付けた設定の登録・呼び出しと、前回使用した設定の自動復元ができます。
- 1周期分のタイマーを、フルHDのMP4動画として書き出せます。

## はじめに使うには

1. [公開ページ](https://jkawamata.github.io/robocontimer/)を開きます。
2. 「大会名（設定名）」を入力します。入力した名前はタイマー画面の左上に表示され、空欄なら非表示になります。
3. 使用する部門を選び、部門名・セッティング時間・試合時間を設定します。
4. 「試合開始から次の試合開始まで」と「共通の開始カウント」を設定します。
5. 効果音やBGMを試聴し、会場に合わせて音量を調整します。
6. 「進行を開始」を押します。音声を使う場合は、音の準備後に約0.6秒待ってから、準備開始の合図とタイマーを同時に始めます。必要に応じて「全画面」で表示します。

まず試す場合は、「登録済みの設定」から「2025年度茨城県大会版（変更不可）」を選び、「読み込む」を押してください。画面上部の「Robocon Timer Maker」を押すと、アプリ内の使い方も開けます。

### インターネット接続なしで使う

「外部通信・ライセンス」を開き、「端末にダウンロード」を押してHTMLファイルを保存します。保存したファイルをブラウザーで開けば、音声を含めてオフラインで利用できます。追加の音源ファイルやインストール作業は必要ありません。

## 大会の進行と時間設定

基本の流れは、次のとおりです。

**セッティング → 共通の開始カウント → 全部門同時スタート → 各部門の試合終了 → 終了表示 → 待機 → 次のセッティング**

セッティングは各部門で同時に始まり、指定した時間が過ぎた部門から準備完了になります。最も長いセッティング時間が終わると、共通の開始カウントへ進みます。

試合の開始時刻は全部門で共通です。試合時間の短い部門は先に「TIME UP」になり、ほかの部門の試合はそのまま続きます。

| 設定 | 内容 |
| --- | --- |
| 試合開始から次の試合開始まで | 全部門に共通の開始間隔。準備・試合・終了表示を含む1周期の長さです。 |
| 部門ごとのセッティング | 準備時間。不要な部門は0秒にできます。 |
| 共通の開始カウント | 全部門の準備が終わってから、試合開始までの時間です。 |
| 部門ごとの試合時間 | 同時スタート後、それぞれの部門が競技する時間です。 |
| 終了表示を残す時間 | 全部門の試合終了後に、終了表示を続ける時間です。 |
| 次の試合へ自動で繰り返す | オンなら同じ周期で次の試合へ進み、オフなら1周期で終了します。 |

待機時間は自動計算されます。準備・開始カウント・試合・終了表示が開始間隔に収まらない場合は、必要な時間を確認画面でお知らせします。

### 標準設定「2025年度茨城県大会版」

| 部門 | セッティング | 試合時間 |
| --- | ---: | ---: |
| 基礎 | 30秒 | 90秒 |
| 制御 | 20秒 | 90秒 |
| 応用 | 0秒 | 150秒 |

共通の開始カウントは30秒、終了表示は30秒、試合の開始間隔は8分です。

この設定では、タイマーの進行が始まってから1分後に第1試合が始まります。第2試合は9分後、第3試合は17分後に始まり、試合の開始時刻が8分間隔になります。8分ごとに繰り返す周期には、次の試合に向けたセッティングと開始カウントも含まれます。

## 進行中の操作

| 操作 | 動作 |
| --- | --- |
| 一時停止 | ボタンを押すと、タイマーと音をすぐに停止します。 |
| 再開 | 一時停止した位置から進行します。停止した分だけ、次の試合開始も遅くなります。 |
| 終了・先頭へ | ボタンを押すと、進行を終了して先頭の開始待ちへ戻ります。 |
| 再生位置バー | 現在の周期内で位置を移動できます。進行中に操作した場合は、離した位置から再開します。 |
| 全画面 | タイマー表示を画面いっぱいに広げます。 |

入力欄などを操作していないときは、`Space`で開始・一時停止、`F`で全画面表示を切り替えられます。

進行中は、音量やBGMのオン・オフ、試合中BGMの曲を変更できます。時間・部門・表示などを変更する場合は、「終了・先頭へ」で開始待ちに戻してください。

開始時の短い待ち時間は、セッティング時間・試合時間・開始間隔に含めません。一時停止からの再開やMP4動画には、この待ち時間を追加しません。

### 別のタブやアプリで作業する場合

通常のタイマーは、別のタブやアプリへ移っても進行を続けます。タブを切り替えるだけでは停止確認は表示しません。元の画面へ戻ると、その時点の経過時間を表示します。

進行中・一時停止中にページを閉じたり再読み込みしたりする場合は、ブラウザーの終了確認が表示されます。ただし、PCのスリープ、ブラウザーの終了、OSなどによるタブの強制休止中は音を再生できません。大会中はPCがスリープしないようにしてください。

## 画面の設定

- 大会名（設定名）は、画面左上に小さなグレーの文字で表示します。
- 部門数に合わせて表示幅を調整します。部門名・色は自由に変更できます。
- 1部門の場合は、開始までの案内に「基礎部門スタートまで」のように部門名を表示します。2・3部門の場合は「全○部門 同時スタートまで」と表示します。
- 文字の太さは「標準・太字・極太」、書体は「ゴシック・丸ゴシック・等幅」から選べます。
- 文字サイズは自動調整のほか、自動調整をオフにして手動で変更できます。
- 終了前警告中は、該当部門の名前と残り時間を明るい赤で表示します。

## 効果音・BGM・ピアノ音

### 効果音

「準備開始」「準備終了」「開始前」「試合開始」「終了前警告」「試合終了」の効果音を内蔵しています。各ボタンで試聴でき、「試聴停止 ■」で止められます。

鳴らし方は「標準・強め・控えめ」から選べます。「終了前の警告」では、何秒前から警告するかを指定します。0秒にすると終了前警告を出しません。

終了前警告では、終了直前の1秒間に警告音とBGMを止め、雷鳴の終了音が鳴る前に間を設けています。

### BGMと分の合図

試合中BGM、試合間BGM、ピアノ音は、それぞれオン・オフを選べます。**セッティング中・共通の開始カウント中はBGMを流しません。**

| 試合中BGM | 曲調 |
| --- | --- |
| 鋼の疾走 | ギター・ベース・ドラムを軸にした、アップテンポで勇ましい合奏曲です。 |
| 回路のパレード（初期選択） | シーケンス、シンセベース、電子ドラム、FM音色を組み合わせたテクノポップです。 |

試合間には、落ち着いた曲を流します。ピアノ音は澄んだ高いド（C6）です。自動繰り返しがオンのとき、次の試合開始までの残り時間が分の区切りになると鳴ります。セッティング開始と重なる場合、その時刻のピアノ音は鳴らしません。

### 音量の初期値

| 音 | 初期音量 |
| --- | ---: |
| 効果音 | 35％ |
| 試合中BGM | 35％ |
| 試合間BGM | 15％ |
| ピアノ音 | 35％ |

4つの音量は個別に調整できます。音量や曲の選択は、通常の進行とMP4書き出しの両方に反映されます。

## 設定の登録・呼び出し

「大会名」と「設定名」は共通です。

1. 大会名（設定名）を入力し、時間・表示・音などを調整します。
2. 「登録」を押して保存します。同名の設定がある場合は「上書き登録」になり、確認が表示されます。
3. 保存した設定を使うときは、「登録済みの設定」で選んで「読み込む」を押します。
4. 不要になった設定は、選択して「削除」から確認後に削除できます。

「2025年度茨城県大会版」は、上書き・削除できない標準設定です。読み込んだ内容を調整して保存する場合は、別の大会名（設定名）で登録してください。通常の設定変更だけでは、名前を付けて登録した内容は書き換わりません。

### 自動保存と保存先

現在の有効な設定は、変更するたびにブラウザー内の保存領域（localStorage）へ自動保存されます。次回は前回の設定を復元し、先頭の開始待ちから始まります。経過時間や試合の途中の位置は保存しません。入力途中で不正な値になった場合は、直前の有効な設定を残します。

設定は、同じ端末・同じブラウザー・同じ公開サイト内で保存されます。GitHubやサーバーには送信されず、別端末との同期や設定ファイルの入出力には対応していません。公開版と端末に保存したHTMLの間でも、設定は自動共有されません。

ブラウザーのデータ削除やプライベート閲覧の終了で、設定が消えることがあります。保存したHTMLの移動・改名時に設定を引き継げるかは、ブラウザーによって異なります。

## MP4を書き出す

タイマーを開始待ちの状態にして、「MP4を書き出す」を押します。最初の準備開始から1周期分の動画を作成し、完了後に自動で保存を開始します。標準設定では8分の動画になります。

- 出力は1920×1080、30fpsを指定した音声付きMP4です。
- 大会名・部門名・色・文字設定・音量・BGMの選択を反映します。
- 動画に入る映像はタイマー表示だけです。**操作の確認・エラーのダイアログや設定画面は映り込みません。**
- 無音区間も音声トラックに含め、映像と音の時間を合わせます。
- 書き出しには、動画の再生時間と同じ時間がかかります。
- 途中でやめる場合は「中止」を押します。中止した動画は保存しません。
- 完了後の動画プレビューは表示しません。保存先の確認ダイアログを出すかどうかは、ブラウザーのダウンロード設定に従います。

| 利用方法 | 別のタブへ移った場合 |
| --- | --- |
| 通常のタイマー進行 | 進行と音の再生を続けます。 |
| MP4書き出し | 映像が止まった動画の保存を防ぐため、書き出しを中止します。 |

**MP4書き出し中は、タイマーのタブを表示したまま、PCをスリープさせずにお待ちください。** 画面更新が長く止まった場合も書き出しを中止します。

MP4録画に対応したブラウザーが必要です。対応状況はアプリの「MP4書き出し」欄に表示します。V1.36はPCのChromeで、別タブでの通常進行、標準8分のMP4、無音での書き出し、中止後の再書き出しを検証しています。

## 外部通信とデータの扱い

タイマーの描画、音の再生、MP4の生成は、ブラウザーの機能を使って端末内で行います。外部ライブラリー・CDN・解析ツール・広告は使用していません。

公開ページを開くときは、GitHub PagesからHTMLを取得します。端末に保存したHTMLは、アプリ本体の動作に外部通信を必要としません。効果音・BGM・ピアノ音はHTMLに内蔵しており、再生のための音源取得もありません。外部サイトへのリンクを開いた場合は、そのサイトへ接続します。

大会名・部門名・設定・生成した動画を、アプリが外部へ送信することはありません。保存したMP4には入力した大会名・部門名が含まれます。
