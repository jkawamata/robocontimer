# Robocon Timer Maker

タイマーに進行を合わせて、ロボコン大会を盛り上げよう！

**公開版：<https://jkawamata.github.io/robocontimer/>**

現在のバージョン：**V1.31**

1〜3部門のロボコンを、セッティングから次の試合まで一定の周期で進行するタイマーです。HTMLファイル1個で動作し、効果音・BGMも含まれています。

## 使い方

1. 大会名（設定名）、使用する部門、部門名、セッティング時間、試合時間を設定します。
2. 試合開始から次の試合開始までの間隔と、共通の開始カウントを設定します。
3. 「進行を開始」を押します。使用する全部門は、共通カウント終了時に同時に試合を開始します。
4. 一時停止・再開、再生位置バー、全画面表示を使って進行します。

タイトルを押すと使い方が開きます。「外部通信・ライセンス」内の「端末にダウンロード」からHTMLを保存して利用できます。設定はこのブラウザー内に自動保存され、次回も復元されます。

## 設定の登録と自動復元

- 「設定の登録・呼び出し」で「大会名（設定名）」を入力し、「登録」を押すと保存できます。一覧から選び、「読み込む」で呼び出します。
- 大会名と設定名は共通です。入力した名前をタイマー画面の左上に表示し、全画面とMP4にも反映します。空欄では非表示になります。以前に登録した設定は、読み込むと登録名を大会名として使います。
- 「2025年度版」を登録済みの設定にあらかじめ追加します。現在の設定や同名の登録内容は上書きしません。追加後は通常の登録設定と同じように上書き・削除できます。
- 同名の「上書き登録」と「削除」には確認が表示されます。普段の設定変更では、名前を付けて登録した内容は変わりません。
- 大会名、使用部門、部門名・色、時間、表示、効果音・BGM・ピアノ音の設定を保存します。有効な設定を変更するたびに自動保存し、次回はその設定で開始待ちになります。経過時間や試合の途中からの再開は保存しません。
- 入力途中の不正な設定は保存せず、直前の有効な設定を残します。進行中に変更した音量やBGMも自動保存します。
- 保存先は同じ端末・ブラウザー・公開サイト内です。別端末との同期や設定ファイルへの書き出しはありません。ブラウザーのデータ削除やプライベート閲覧の終了で消えることがあります。HTMLファイルの移動・改名時の引き継ぎはブラウザーによって異なります。
- 「2025年版に戻す」で初期設定に戻せます。登録済みの設定は削除しません。

## 音の設定

- 効果音・試合中BGM・試合間BGM・ピアノ音の音量を個別に調整できます。
- 初期音量は、効果音35％、試合中BGM35％、試合間BGM15％、ピアノ音35％です。
- 試合中BGM、試合間BGM、ピアノ音は個別にオン・オフを選べます。
- セッティング中・開始カウント中はBGMを流しません。
- ピアノ音はグランドピアノの録音サンプルによる高いド（C6）です。残響を控え、澄んだ響きになるよう調整しています。次の試合開始まで残り○分の区切りに鳴ります。セッティング開始と重なる時刻には鳴りません。
- 試合中BGMは「試合中BGMの曲」で選べます。初期選択は「鋼の疾走」で、「2025年版に戻す」でも「鋼の疾走」になります。
  - 「鋼の疾走」：ギター・ベース・ドラムを軸にした合奏曲（160 BPM・2分）。
  - 「回路のパレード」：シーケンス、シンセベース、電子ドラム、FM音色を組み合わせたオリジナルのテクノポップ（132 BPM・約2分11秒）。
- 各曲にAメロ・Bメロ・サビ・間奏を設け、曲調に変化をつけています。
- 選択した曲が試聴・試合進行・MP4書き出しに反映されます。進行中の切り替えは試合経過時間に合わせ、書き出し中は選択を固定します。
- 「試合中BGM ▶」では全曲を試聴できます。「試聴停止 ■」で途中でも止められます。

大会名の入力欄の案内文は半透明で表示します。通常の操作通知は表示せず、設定の不備や動作エラーは「確認」で閉じる中央のダイアログに表示します。

## MP4書き出し

「MP4を書き出す」で、先頭の準備から1周期分の動画を作成します。設定した音量・大会名・部門名が動画に反映され、完了すると自動で保存が始まります。

- 1920×1080、30fpsを指定して書き出します。
- 書き出しには再生時間と同じ時間がかかります。処理中はこのタブを表示したままにしてください。
- MP4録画をサポートするブラウザーが必要です。対応状況は画面に表示します。
- 保存先ダイアログを表示するかどうかは、ブラウザーのダウンロード設定に従います。

## 外部通信とデータ

外部ライブラリー・CDN・解析ツール・広告は使用していません。タイマーの描画、音の再生、MP4生成は端末内で処理し、設定や動画を外部に送信しません。

公開ページを開く際はGitHub PagesからHTMLを取得します。端末に保存したHTMLは、インターネットに接続せずに利用できます。ライセンスのリンクを開く際には外部サイトへ接続します。
